## ⚔️ Main Bar

---

### 💎 MyStart (Start Menu)

<table>
<tr>
<td width="50%">

**MyStart Launcher**



![A1](Images/A1.png)



MyStart is a custom mini-launcher that opens on a hotkey (`End` key by default, held with `Left Ctrl`). It scans a configurable folder for `.lnk` shortcuts and displays up to 16 of them as icon tiles.

</td>
<td width="50%">

**MyStart — My Own Config**



![A2](Images/A2.png)



**Don't use the default Desktop folder.** Create a dedicated folder anywhere you like, fill it with your own `.lnk` shortcut files and custom `.ico` icons, then point MyStart at that folder in Settings. This gives you a clean, curated launcher completely separate from your Desktop clutter. The bar itself also uses `icons\a1.ico` as the clickable MyStart button — replace it with any icon you want.

</td>
</tr>
</table>

---

### 💎 App Name Menu & Quick Actions

<table>
<tr>
<td width="50%">

**App Name Menu**



![A3](Images/A3.png)



The leftmost button always shows the name of the currently active application. You can assign a **custom display name** to any process via the Custom App Name feature (`Ctrl+G` by default): map any `.exe` name to whatever label you want shown in the bar. The bar's own process is automatically registered as `"MyStart"`.

</td>
<td width="50%">

**Quick Actions Menu**



![A4](Images/A4.png)



One-click access to the most common window operations without opening a submenu.

</td>
</tr>
</table>

---

### 💎 Settings Menu & Jump To Menu

<table>
<tr>
<td width="50%">

**Settings Menu**



![A5](Images/A5.png)



Direct links to 19 Windows system panels: Main Settings, Personalization, Windows Security, Apps & Features, Default Apps, Task Manager, Control Panel, Device Manager, Services, Firewall, Disk Cleanup, and more — all in one click.

</td>
<td width="50%">

**Jump To Menu**



![A6](Images/A6.png)



Instantly open any of your configured folders in Explorer. Fully customizable paths and hotkeys from the Settings GUI.

</td>
</tr>
</table>

### 💎 Tools Menu & Window Position Menu

<table>
<tr>
<td width="50%">

**Tools Menu**



![A7](Images/A7.png)



Built-in shortcuts to system utilities: Mouse Pointer settings, Power Options, Action Recorder (PSR), Power & Sleep, Date & Time, Screenshot (`Win+Shift+S`), UAC Settings, DirectX Diagnostic, CMD, CMD (Admin), PowerShell, and PowerShell (Admin).

</td>
<td width="50%">

**Window Position Menu**



![A8](Images/A8.png)



Snap the active window to any of 9 positions on screen: Up, Down, Left, Right, Center, and all four corners — each with its own assignable hotkey (`Alt+Numpad` by default).

</td>
</tr>
</table>

### 💎 Resize Menu & Action Menu

<table>
<tr>
<td width="50%">

**Resize Menu**



![A9](Images/A9.png)



Apply any of your 9 configured size presets to the active window instantly, with hotkey support.

</td>
<td width="50%">

**Action Menu**



![A10](Images/A10.png)



Minimize the active window, minimize all others, minimize everything, restore the last minimized window, or restore all — all with dedicated hotkeys (`Alt+E`, `Alt+I`, `Alt+G`, `Ctrl+Alt+Z`, `Ctrl+Alt+G`).

</td>
</tr>
</table>

### 💎 Apps Menu & VD Menu

<table>
<tr>
<td width="50%">

**Apps Menu**



![A11](Images/A11.png)



Launch any of your 12 configured applications directly from the bar, with hotkey support.

</td>
<td width="50%">

**VD Menu**



![A12](Images/A12.png)



Full Windows Virtual Desktop management: go to a desktop (`Ctrl+Numpad1–9`), throw the active window and follow (`Ctrl+Win+Numpad1–9`), throw without following (`Win+Alt+Numpad1–9`), create a new desktop (`Alt+F12`), remove the current one (`Alt+F11`), pin/unpin the active window (`Alt+Numpad0`), and integrate with Rainmeter VDN skins.

</td>
</tr>
</table>
